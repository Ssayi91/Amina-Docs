01. Project Overview

The "Between Two Worlds" platform was custom-engineered to reflect a unique, nuanced digital experience. It features a distinct editorial aesthetic, utilizing a strict geometric layout, custom typography, and dynamic content galleries.

The backend architecture has been specifically designed to allow seamless content updates while preserving the integrity of the core design and structural code.

03. Operational Guidelines

Content vs. Structure

You have full administrative control over the Content (text and media). You must not alter the Structure (layout, schema configurations, or navigation menus). The system is engineered to auto-format your content.

04. CMS Execution Guide

Navigation Protocol: Bypass the side menus. Utilize the Search Bar at the top of the dashboard. Type the target document name (e.g., "Identity", "Images") and select it directly.

Protocol 1: Text Updates
  1. Search for the target section.
  2. Modify the text blocks directly.
  3. Mandatory: Click the green "Publish" button in the top-right corner to deploy changes to the live site.
Protocol 2: Media Replacement
  1. Search for "Images" or "Gallery".
  2. Select the existing asset, click the ellipsis (...), and choose "Replace".
  3. Upload the new file and click "Publish".

Restricted Actions

To maintain system stability, do not interact with:

  • Settings / Configuration schemas.
  • Navigation or routing structures.
  • Document deletion (use "Unpublish" or clear text instead).
